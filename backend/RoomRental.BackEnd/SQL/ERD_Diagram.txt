┌──────────────────────────────────────────────────────────────┐
│                  RELATIONSHIP SUMMARY                         │
└──────────────────────────────────────────────────────────────┘

1. Roles → Users (1:N)
   ├─ 1 Role có nhiều Users
   └─ 1 User thuộc 1 Role

2. Users (Landlord) → Posts (1:N)
   ├─ 1 Landlord có nhiều Posts
   └─ 1 Post thuộc 1 Landlord

3. Posts → Rooms (1:1)
   ├─ 1 Post có 1 Room
   └─ 1 Room thuộc 1 Post (UNIQUE constraint)

4. Posts → PostImages (1:N)
   ├─ 1 Post có nhiều Images
   └─ 1 Image thuộc 1 Post

5. Users (Tenant) → Favorites (1:N)
   ├─ 1 Tenant có nhiều Favorites
   └─ 1 Favorite thuộc 1 Tenant

6. Posts → Favorites (1:N)
   ├─ 1 Post có nhiều Favorites
   └─ 1 Favorite thuộc 1 Post

7. Users (Tenant) → ViewingAppointments (1:N)
   ├─ 1 Tenant có nhiều Appointments
   └─ 1 Appointment thuộc 1 Tenant

8. Posts → ViewingAppointments (1:N)
   ├─ 1 Post có nhiều Appointments
   └─ 1 Appointment thuộc 1 Post

9. Posts ↔ Amenities (M:N via PostAmenities)
   ├─ 1 Post có nhiều Amenities
   ├─ 1 Amenity thuộc nhiều Posts
   └─ Bảng trung gian: PostAmenities

┌──────────────────────────────────────────────────────────────┐
│                   ENUM VALUES REFERENCE                       │
└──────────────────────────────────────────────────────────────┘

PostStatus (Posts.Status):
  0 = Pending (Chờ duyệt)
  1 = Approved (Đã duyệt)
  2 = Rejected (Bị từ chối)
  3 = Hidden (Đã ẩn)
  4 = Expired (Hết hạn)

RoomStatus (Rooms.Status):
  0 = Available (Còn trống)
  1 = Rented (Đã cho thuê)
  2 = TemporarilyUnavailable (Tạm không khả dụng)

AppointmentStatus (ViewingAppointments.Status):
  0 = Pending (Chờ xác nhận)
  1 = Approved (Đã chấp nhận)
  2 = Rejected (Bị từ chối)
  3 = Cancelled (Đã hủy)
  4 = Completed (Đã hoàn thành)


┌──────────────────────────────────────────────────────────────┐
│                   BUSINESS RULES                              │
└──────────────────────────────────────────────────────────────┘

1. Role Rules:
   ✓ Chỉ có 3 Roles: Tenant, Landlord, Admin
   ✓ Tenant: Tìm phòng, yêu thích, đặt lịch hẹn
   ✓ Landlord: Đăng tin, quản lý tin đăng
   ✓ Admin: Duyệt tin, quản lý user, quản lý tiện ích

2. Post Rules:
   ✓ Mỗi Post phải có đúng 1 Room (1:1)
   ✓ Post mới tạo có Status = Pending
   ✓ Chỉ Post Approved mới hiển thị công khai
   ✓ Landlord có thể ẩn tin (Status = Hidden)

3. Room Rules:
   ✓ Room không thể tồn tại độc lập (phụ thuộc Post)
   ✓ Địa chỉ đầy đủ: Province + District + Ward + Address

4. Favorite Rules:
   ✓ 1 User không thể favorite cùng 1 Post 2 lần
   ✓ UNIQUE constraint: (UserId, PostId)

5. Appointment Rules:
   ✓ Tenant tạo lịch hẹn → Status = Pending
   ✓ Landlord approve/reject → Status thay đổi
   ✓ ScheduledAt phải > CreatedAt

6. Image Rules:
   ✓ Ảnh có DisplayOrder thấp nhất = Thumbnail
   ✓ DisplayOrder = 0 → Ảnh đại diện chính

7. Amenity Rules:
   ✓ Admin quản lý danh sách Amenities
   ✓ Landlord chọn Amenities khi đăng tin
   ✓ M:N relationship qua PostAmenities


┌──────────────────────────────────────────────────────────────┐
│                   SECURITY NOTES                              │
└──────────────────────────────────────────────────────────────┘

⚠ Password Security:
  - PasswordHash được tạo bằng BCrypt.Net-Next
  - Không lưu plaintext password
  - Cost factor khuyến nghị: 11-12

⚠ SQL Injection Prevention:
  - Sử dụng Parameterized Queries
  - Không concat string trong SQL
  - EF Core tự động handle

⚠ Data Privacy:
  - Email là UNIQUE (không trùng)
  - Phone number có thể trùng (optional)
  - Avatar URL có thể NULL

⚠ Soft Delete:
  - Hiện tại: Hard delete
  - Có thể thêm IsDeleted column nếu cần
